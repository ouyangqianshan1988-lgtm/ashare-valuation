# 方寸估值 · A 股价值研究台

中文 A 股研究网站：名称/代码检索、真实行情与年度财报、可调整的三情景 FCFF 估值、反向 DCF、敏感性矩阵和数据缺口提示。

网站：https://ouyangqianshan1988-lgtm.github.io/ashare-valuation/

## 使用

1. 输入公司简称或六位代码并选择股票。
2. 核对行情日期、年度财报期及数据来源。
3. 如果债务或折旧明细不全，补充输入；也可明确选择“采用已披露合计作假设”。这个操作不把缺失项目变成已证实的零。
4. 修改悲观/基准/乐观的增长率、利润率、折现率、终值与投入假设，再计算。

## 数据和方法

- 腾讯财经：个股价格、涨跌、市值、PE/PB 和股本快照。
- 东方财富：年度利润表、资产负债表、现金流量表和财务指标。
- 巨潮资讯：页面提供原始公告检索入口，当前未自动逐项核验。
- 方法参考 [SherryCW/dcf-sherry](https://github.com/SherryCW/dcf-sherry) 的筛选、定价、质量检查分层原则。此仓库独立实现，不复制原仓库代码，不声称完整实现其治理工作簿或原始证据审核。

GitHub Actions 在北京时间每天 18:35 计划采集并发布，实际执行时间可能延迟；支持手动运行。非交易日行情日期仍为最近交易日，年度财务数据仅随所采集报告更新。公开数据接口可能限流、变更或失效，失败时保留最后成功数据并显示原日期。数据源权益属于原提供者，代码许可不授予第三方数据再分发权；部署者应根据用途核对提供者条款。

## 重要口径

- 首版为年度基期五年 FCFF 模型，不是 TTM；不自动并入较新季报，也未滚动调整财报日至行情日的分红、回购及融资。
- 普通经营企业先按行业规则路由为 FCFF 候选，不代表已证明“结构性增长”。银行、保险、证券、房地产及识别出的强周期行业不给出普通 DCF 价格。
- EBIT 近似取营业利润加财务费用，未逐项剔除投资及非经常性收益。
- 营运资本只覆盖存货、应收票据及账款、应付票据及账款；现金是账面货币资金，未扣受限资金；少数股东权益按账面值处理。
- 股数使用行情总股本，未核实未来稀释或多地上市价差。
- 起始增长率 3%/7%/11%、WACC 11%/9.5%/8%、终值增长 1.5%/2%/2.5% 和终值 ROIC 12% 都是统一试算假设，不能视为个股预测或机构共识。
- 未取得可信前瞻一致预期，PEG 不计算。历史增长率绝不充作 PEG 分母。
- 缺失输入为 BLOCKED；可计算结果始终为 DRAFT_REVIEW，不能作为买卖指令。

完整公式及接口见 [engine-contract.md](docs/engine-contract.md)。

## 本地运行

无需安装第三方依赖，Python 3.12+、Node 22+：

```text
python scripts/collect.py
python scripts/serve.py
python -m unittest discover -s tests -p "test_*.py"
node --test tests/valuation.test.mjs
python scripts/verify_site.py
```

预览地址 `http://127.0.0.1:8766`。网站为静态文件，浏览器只读取同源 JSON；无需输入任何 API 密钥。输入只在当前页面内存中使用，不上传、不持久保存。
