# 方寸估值 · A 股价值研究台

中文 A 股研究网站：名称/代码检索、真实行情与年度财报、可调整的三情景 FCFF 估值、反向 DCF、敏感性矩阵和数据缺口提示。

网站：https://ouyangqianshan1988-lgtm.github.io/ashare-valuation/

## 使用

1. 输入公司简称或六位代码，选择股票或点击“一键估值”。
2. 直接查看自动估值区间，无需填写参数或勾选确认。
3. 详细来源和参数默认折叠，需要时可展开查看或修改。

## 数据和方法

- 腾讯财经：个股价格、涨跌、市值、PE/PB 和股本快照。
- 东方财富：年度利润表、资产负债表、现金流量表、财务指标，以及公司机构盈利预测汇总。
- 巨潮资讯：页面提供原始公告检索入口，当前未自动逐项核验。
- 方法参考 [SherryCW/dcf-sherry](https://github.com/SherryCW/dcf-sherry) 的筛选、定价、质量检查分层原则。此仓库独立实现，不复制原仓库代码，不声称完整实现其治理工作簿或原始证据审核。

GitHub Actions 在北京时间每天 18:35 计划采集并发布，实际执行时间可能延迟；支持手动运行。非交易日行情日期仍为最近交易日，年度财务数据仅随所采集报告更新。公开数据接口可能限流、变更或失效，失败时保留最后成功数据并显示原日期。数据源权益属于原提供者，代码许可不授予第三方数据再分发权；部署者应根据用途核对提供者条款。

## 重要口径

- 首版为年度基期五年 FCFF 模型，不是 TTM；不自动并入较新季报，也未滚动调整财报日至行情日的分红、回购及融资。
- 普通经营企业先按行业规则路由为 FCFF 候选，不代表已证明“结构性增长”。银行、保险、证券、房地产及识别出的强周期行业使用同行倍数相对估值；现金流不支持正估值时也切换至该方法。
- EBIT 近似取营业利润加财务费用，未逐项剔除投资及非经常性收益。
- 营运资本只覆盖存货、应收票据及账款、应付票据及账款；现金是账面货币资金，未扣受限资金；少数股东权益按账面值处理。
- 股数使用行情总股本，未核实未来稀释或多地上市价差。
- 不再自动使用统一的 3%/7%/11% 增速。每日从东方财富公司盈利预测接口采集按年营收、营业利润、EPS、指标机构数和已返回研报日期，保存于 `site/data/forecasts.json`。无预测、连续年份不足、营收/营业利润预测机构少于 2 家、采集超过 7 天或最近已返回研报超过 180 天时，改用历史与同行数据自动预测。
- 前 2–3 年营收来自机构汇总；EBIT 近似利润率 = 预测营业利润 / 预测营收 + 基期财务费用 / 基期营收，这一口径转换属于模型假设。后续年份的增速线性回落至初始永续增长率，利润率维持最后预测年。悲观/乐观将营收乘 90%/110%，利润率减去/加上其绝对值的 10%（亏损时也保持方向正确），并非机构低/高预测。
- 无有效机构预测时，增长由自身历史60%与同行40%组合，限定−10%至30%，五年收敛至2%；利润率逐步靠近同行，亏损不假定自动扭亏。
- 折现率按8.5%基准叠加市值、杠杆及行业因素；预测税率采用合理范围内历史值、同行或25%规则。终值ROIC参考历史或同行并限定5%–25%。这些均为系统假设，情景权重不代表发生概率。
- 缺失财务项目使用已披露小计、同行比例或规则估计，原始记录保持不变。债务/折旧未披露部分暂按零可能低估；折叠详情展示规则与来源。
- 每日生成 `site/data/estimates.json`，保存每家公司的自动假设和结果；过期或不匹配时浏览器按相同规则重新计算。
- 机构 EPS 只用于按现价计算前瞻 PE，不当作营收增速。汇总的不同字段可能来自不同机构和日期；最近返回研报日期不代表整个汇总的更新时间。该年度模型以财报年末为基期，未滚动扣除已过去期间的现金流，输出不等于今日公允价值。
- 未取得可信前瞻一致预期，PEG 不计算。历史增长率绝不充作 PEG 分母。
- 仅当数据不足以支持任何模型时停止输出。可计算结果为条件估计，仍保持 DRAFT_REVIEW 状态。

完整公式及接口见 [engine-contract.md](docs/engine-contract.md)。

## 本地运行

无需安装第三方依赖，Python 3.12+、Node 22+：

```text
python scripts/collect.py
node scripts/build_estimates.mjs
python scripts/serve.py
python -m unittest discover -s tests -p "test_*.py"
node --test tests/*.test.mjs
python scripts/verify_site.py
```

预览地址 `http://127.0.0.1:8766`。网站为静态文件，浏览器只读取同源 JSON；无需输入任何 API 密钥。输入只在当前页面内存中使用，不上传、不持久保存。
