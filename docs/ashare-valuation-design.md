# A 股估值网站：首版方案

状态：用户已于 2026-09-17 确认实现；按该方案开发并验证发布。

## 目标与页面

在用户 GitHub 账户下建立独立仓库 ashare-valuation，并用 GitHub Pages 发布中文、手机可用的网站。输入 A 股代码或名称，选择公司后查看行情日期、财报期、估值方法、三情景估值区间、概率加权值、反向 DCF 和质量检查。展示事实、计算结果和主观假设的区别。

## 推荐架构

GitHub Pages 提供页面；GitHub Actions 定时获取行情及财务数据，生成带来源和日期的数据快照；浏览器根据明确假设计算估值。凭据只存在仓库 Secrets 中。发布前核对数据来源允许的公开展示范围。首次接入需要实测覆盖范围和稳定性，不能提前承诺全市场财务字段齐全。

方案比较：每日数据快照适合无需额外服务器的首版；实时接口需要另外托管后端及处理额度；手动导入最容易审计，但不能满足自动查询体验。推荐每日快照，保留手动补充缺失数据的能力。

## 估值规则

参考 https://github.com/SherryCW/dcf-sherry 的三层方法。实现独立网站并注明方法来源；复用代码前核实授权范围。

- 先判断公司类型与适用方法。首版普通经营企业使用 FCFF DCF，金融、地产与强周期企业提示专用模型需求，不能套用普通 DCF 输出价格。
- 预测由营收、利润率、税率、折旧、资本支出、营运资本驱动，禁止直接把经营现金流当 FCFF。
- 提供悲观、基准、乐观情景及明确概率，展示现金、债务、少数股东权益等价值调整与股数口径。
- 提供 WACC × 永续增长率敏感性、隐含永续增长率及增长持续期。持续期求解明确注明其外推假设。
- 无前瞻一致预期时不计算 PEG，不用历史增速替代；用户假设不能冒充机构一致预期。
- 检查 WACC 大于永续增速、概率合计、有限数值、终值占比、再投资一致性及增长质量。
- 缺失关键事实时 BLOCKED；证据或独立审核不足时 DRAFT_REVIEW；不自动把可计算结果标成 PASS。

## 数据与故障

优先验证无需用户付费的公开来源；若覆盖不足，考虑用户已有且允许公开展示的数据服务。保留来源链接、报告日期、行情日期和抓取时间。数据更新失败保留最后成功快照，明确显示过期状态；无数据时显示原因，不生成替代数字。演示数据单独标注，不能冒充真实股票估值。
