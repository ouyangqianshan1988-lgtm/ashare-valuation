# A 股估值网站 Implementation Plan

> **For agentic workers:** Use subagent-driven-development for the isolated calculation engine and independent review; the owning agent implements data collection, UI and deployment.

**Goal:** Publish a Chinese A-share valuation research website with real third-party snapshots on GitHub Pages.

**Architecture:** Standard-library Python collects public quotes and financial records into static JSON. Browser ES modules perform transparent FCFF scenario calculations. GitHub Actions refreshes data and deploys Pages.

**Tech Stack:** Python 3.12, vanilla HTML/CSS/JavaScript ES modules, Node built-in tests, GitHub Actions/Pages.

## Global Constraints

- Never invent missing financial facts or silently replace missing values with zero.
- Current facts and user-adjustable judgments must be visibly separate.
- Missing required input returns BLOCKED; unreviewed scenarios return DRAFT_REVIEW.
- Financial, real-estate and strong cyclical companies must not automatically receive ordinary FCFF valuations.
- WACC > terminal growth; probabilities sum to one; all model inputs/results finite.
- Historical growth is not forward consensus and is not a PEG denominator.
- Source names, report dates, quote dates and collection timestamps are shown.
- Public site and source contain no credentials or private user data.

## Task 1 — Independently testable valuation engine

Files: site/valuation.mjs, tests/valuation.test.mjs, docs/engine-contract.md.
Interface: evaluate(company, assumptions) returns status, errors, warnings, scenarios, weightedValue, sensitivity, reverse. Company financial amounts and shares use base CNY/share units.

- [ ] Write tests for a hand-calculated constant-cash-flow company, missing fields, invalid rates, bridge, probability, routing and inverse solutions; run node --test tests/valuation.test.mjs and confirm failure before implementation.
- [ ] Implement five-year revenue-driven FCFF: EBIT × (1-tax) + depreciation - capex - change in operating working capital. Terminal FCFF uses NOPAT × (1-g/ROIC), preserving reinvestment consistency.
- [ ] Implement bear/base/bull scenario discounting and EV-to-equity bridge; sensitivities; implied terminal growth and extension duration by bounded solve.
- [ ] Run engine tests and document exact contract, warnings and independent-check examples.

## Task 2 — Real data acquisition

- [ ] Probe Tencent quotes and Eastmoney financial records. Confirm unit definitions and publication/report dates using returned field names.
- [ ] Test null-safe parsers, date selection and stale-cache merge with python -m unittest discover -s tests before implementation.
